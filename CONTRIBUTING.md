Thank you for considering contributing to React Email.

We've created this guide to help you better understand how to contribute to the project, even if you've never contributed to an open source project before.

## How to report bugs

To report a bug, please first read our guide on [opening issues](https://react.email/docs/contributing/opening-issues).

## How to contribute code

To open a pull request, please first read our guide on [opening pull requests](https://react.email/docs/contributing/opening-pull-requests), which outlines our process for RFCs and pull requests.

## AI-assisted contributions

You're welcome to use AI tools to explore the codebase, draft changes, and write tests. You are still responsible for everything you submit.

1. **Understand your change.** Read every line before opening the pull request, and be ready to explain it in review. The pull request template asks you to confirm this.
2. **Write the description yourself.** Pull request descriptions, issues, and comments should be in your own words. Using AI to translate is fine.
3. **Disclose AI use.** Tick the checkbox in the pull request template if AI tools wrote part of the change.
4. **Don't let agents open pull requests on their own.** A person must review and submit every contribution.
5. **Don't mass-submit low-quality pull requests.** We treat that as spam and may close the pull requests and block the account.

If you're using a coding agent, it will pick up the rules in [AGENTS.md](./AGENTS.md).
