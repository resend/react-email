## 1. Install dependencies

Get the [react-email](https://www.npmjs.com/package/react-email) package and the [eusend Node.js SDK](https://www.npmjs.com/package/@eusend_dev/sdk).

<CodeGroup>

```sh npm
npm install @eusend_dev/sdk react-email
```

```sh yarn
yarn add @eusend_dev/sdk react-email
```

```sh pnpm
pnpm add @eusend_dev/sdk react-email
```

```sh bun
bun add @eusend_dev/sdk react-email
```

</CodeGroup>

## 2. Create an email using React

Start by building your email template in a `.jsx` or `.tsx` file.

```tsx email.tsx
import { Button, Html } from "react-email";

interface EmailProps {
  url: string;
}

export function Email({ url }: EmailProps) {
  return (
    <Html lang="en">
      <Button href={url}>Click me</Button>
    </Html>
  );
}
```

## 3. Send email

<Info>Pass your template to the `react` prop and the eusend SDK renders it to HTML locally before sending, so the JSX never leaves your machine.</Info>

Import the email template you just built and use the eusend SDK to send it.

```tsx
import { Eusend } from "@eusend_dev/sdk";
import { Email } from "./email";

const eusend = new Eusend(process.env.EUSEND_API_KEY);

await eusend.emails.send({
  from: "you@example.com",
  to: "user@gmail.com",
  subject: "hello world",
  react: <Email url="https://example.com" />,
});
```
